# Changelog

All notable changes to EveryConfig are documented in this file.
Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/);
versioning follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0]

- Initial release.
- `ConfigAdapter` / `ConfigAdapterRegistry` with lazy registration and preference ordering.
- Cloth Config, YACL and REI adapters.
- `configEmbed` element for Hellow pages, with `library`, `libraries` and `height` options.
- Placeholder when no supported config library is installed.
